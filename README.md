### 🚀 Notable Projects

**[Human or Machine?](https://github.com/alpha-endgame/Human-or-Machine.)**  
A text-classification machine learning system that uses a Random Forest model to determine whether text is human-written or AI-generated. It features linguistic feature engineering (like readability indexes and word counts), feature-integrity auditing, and an interactive Gradio web dashboard.  
*Tech stack: Python, Pandas, NumPy, Scikit-learn, Random Forest, Gradio*

**[Social Sentinel](https://github.com/Wecncode/Social-Sentinel)**  
An open-source NLP tool and interactive application designed to analyze text messages and emails for social engineering tactics and phishing threats. It evaluates indicators like artificial urgency and psychological manipulation using multi-model classification algorithms.  
*Tech stack: Python, Scikit-Learn, TF-IDF, Gradio*
